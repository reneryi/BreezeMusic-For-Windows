# BreezeMusic · 微风音乐 (Windows 桌面概念版 v1.3.2 · Skyline Edition)

基于 **Rust + Tauri 2.0 + Vue 3 (TypeScript + Pinia)** 构建的第三方「酷狗概念版 (`appid=3116`, `clientver=11440`)」Windows 桌面客户端。

## 一、核心设计理念：方案二「顶部天际线中枢画廊 (Skyline Command & Bento)」

1. **彻底告别左侧导航栏审美疲劳**：
   - 移除传统 `220px` 左侧固定导航栏，将导航、搜索与个人身份收拢至 **顶部天际线中枢 (`TitleBar.vue`)**，释放 **100% 全宽无遮挡桌面画布**。
   - **顶部流光数字身份舱**：右上角常驻展示 `[头像] 昵称 · ✦ Lv.11 · 累计听歌 X 小时 Y 分`（带 CSCC 实时听歌心跳指示灯）与 `👑 VIP 已签 / 领今日 VIP` 鎏金入口。
2. **软润饱满双色矢量图标 (`PlumpIcon.vue`) + 100% 零边框线设计 (Borderless Tonal UI)**：
   - 对齐 Android 端 `NowPlayingCanvasControls.kt`，全量重绘软润饱满的大圆角贝塞尔填充图标与双色微光层次，彻底弃用细线条线框图标。
   - 全局移除 `1px solid` 线框分割，采用 **无框色阶高差 (Surface Elevation)**、柔和空气感投影与 120fps 欠阻尼弹簧过渡。
3. **Android 端 (`reneryi/breezemusic` v1.3.2) 全功能对等移植与桌面级升华**：
   - **探索发现 (`DiscoverView.vue`)**：
     - 首屏黄金双子星：**三封面交错立体叠层 (`StaggeredThreeCovers`) 每日推荐卡** + **实时可交互「猜你喜欢 · 随心听」私人 FM 卡**（含 20 首漫游候选池抽屉与 `+20首` 无缝续杯）。
     - **新歌速递**：首页 5 语种 `3×3` 微卡网格；独立页面采用 **精确发行日期 (`yyyy-MM-dd`) 折叠时间轴 + 右侧悬浮 A-Z 首字母快速索引条**。
     - **精选场景电台走廊** 与 **巅峰排行榜画廊**（含全部榜单分类宫格选择器、左窄右宽双栏榜单工作台、榜内实时搜索与当前播放歌曲定位）。
   - **随心听调频台 (`RadioView.vue`)**：
     - 复古未来主义 **旋转电台黑胶 + 发光 FM 赫兹刻度调谐器 (`FM 88.0 ~ 108.0 MHz`)** + 分类电台矩阵与漫游曲目池。
   - **我的音乐资产 (`LibraryView.vue`)**：
     - 上层 **快捷三联胶囊矩阵**（我喜欢的音乐、最近播放、概念胶囊 `Focus Pod` 番茄钟 × 4 路程序化白噪音混音台）。
     - 下层 **四维无框滑块 Tab (`自建歌单 / 收藏歌单 / 关注歌手 / 已购音乐`)**，支持新建/删除歌单、批量匹配导入外部歌单、左窄右宽同屏展开歌单/歌手主页 (`ArtistDetail`) / 专辑详情 (`AlbumDetail`)。
   - **平板级双栏沉浸播放舞台 (`NowPlayingView.vue`)**：
     - 沿用并升华 Android 平板横屏 `LandscapePlayerPage.kt`（左 `46%` 视觉控播舞台 : 右 `54%` 全高无框上下渐隐 KRC 逐字歌词舞台）。
     - 封面舞台右下角竖向锚定 **「♥ 红心收藏 / ➕ 加歌单 / ✨ 2K 歌词海报工坊」** 三枚软润按钮；支持双击封面红心收藏、右键预览保存 1000P 高清原图。
     - 内置 **64-bit 风格母带级 WebAudio DSP 调音台**（10 段参量均衡器 + 5 大目标参考曲线 + A/B/C 自定义记忆槽 + 声场调音工作台）、**歌曲评论抽屉（热评/最新）**、**前奏/间奏三点呼吸波点** 与 **播放 ↔ 暂停 880ms 连续动量过渡 (`playMomentum`)**。
   - **Master-Detail 桌面设置中心 (`SettingsPlaceholderView.vue`)**：
     - 左分类导航 + 右无框卡片面板，涵盖视听外观、母带音效、歌词校准、全局快捷键、四维缓存分项清理，以及 **合规隐藏式「音乐下载与歌词保存」解锁开关**。

## 二、快速运行与构建指南

```bash
npm install
npm run tauri dev
```
